Architecture & Codebase

Core iOS developer on a multi-tenant medical assessment platform — a 200+ Swift file codebase running MVVM + Coordinator with a protocol-oriented networking layer, UIKit-SwiftUI hybrid rendering, and on-device TFLite pose estimation. The app ships across 10 build targets (EMMA, EMMADEV, EMMASTG, EMMAUAT, ATHLETE, ATHLETEDEV, ATHLETESTG, ATHLETEUAT, MYBACKHUB, MYBACKHUBSTG) using per-environment conditional compilation via Swift compiler flags and CocoaPods dependency management.

Key Contributions

  • Biometric Assessment Pipeline — Architected and shipped the core feature end-to-end. The BiometricViewModel (3,033 lines, 70+ @Published properties) orchestrates: exercise list → caution popup → movement guideline → real-time camera capture with MoveNet pose estimation → rep counting / orientation validation → multipart video upload → server-side queue polling via 15-second heartbeat timer → AI-generated report delivery. Handles 66+ exercise types across ROM, Strength, and Posture categories with full state machine including pause/resume, retake, and skip logic.
  • On-Device Pose Estimation Engine — Integrated TensorFlow Lite (MoveNet Lightning & Thunder, PoseNet) into the AVFoundation camera pipeline. The system performs real-time 17-keypoint detection on CVPixelBuffer with smart crop region tracking, keypoint score filtering, EMA smoothing for touch-hands exercises, orientation classification (front/back/left/right), body-in-frame validation with cumulative outside-frame thresholds to filter ML jitter, and rep counting for strength assessments — all rendering a UIKit skeleton overlay on a SwiftUI host. Configurable via MetalDelegate for GPU acceleration on supported devices.
  • Deep Drive Analysis — Built a sports performance module with a protocol-oriented ViewModel pattern. Features a guided video upload flow using PhotoPicker + AVFoundation, JWT-authenticated REST API endpoints for submitting exercises and retrieving AI-generated performance reports, and an async queue-based processing pipeline with status polling. Handles multiple video uploads per sports assessment with individual progress tracking and error recovery.
  • UIKit-SwiftUI Bridge for Camera — Architected the MovementViewController (2,532 lines) as a UIViewControllerRepresentable bridge, wrapping AVCaptureSession configuration, real-time ML inference loop, audio playback for exercise instructions and countdown, full-body negative feedback sounds, carry test distance estimation, and 60-second strength countdown timer — all within a SwiftUI NavigationStack-based coordinator.
  • Real-Time Telemedicine — Integrated WebRTC for video/audio and Socket.IO for signaling protocol, enabling clinicians to conduct live remote sessions. Features in-call movement guideline overlays, recording controls, camera toggle, and speaker switching. Built with a protocol-oriented TelemedicineViewModel separating WebRTC management, socket communication, and local media state.
  • Speech-Driven Assessment Flow — Implemented simultaneous Text-to-Speech (AVSpeechSynthesizer) and Speech-to-Text (SFSpeechRecognizer + AVAudioEngine) for pain question answering. Features answer normalization with configurable confidence thresholds, checkbox mode with auto-submit timeout, audio interruption recovery (phone call handling via interruption lock), user speech detection to pause TTS, thread-safe audio queue via dedicated dispatch queue, and 6-second listen timeout with retry logic.
  • Coordinator-Based Navigation — Built a SwiftUI NavigationStack Coordinator with 42+ Page enum destinations, Sheet and FullScreenCover enums for modal presentations, and popToRoot/replaceStack/resetNavigation navigation controls. Integrated a DeepLinkManager handling sign-in, sign-up, and package-details URL schemes with deep link verification flow.
  • Multi-Tenant Architecture — Implemented 10 build targets with Swift conditional compilation (#if ATHLETE, #if EMMADEV, etc.) managing per-tenant brand differentiation, API host resolution via DefaultTenant singleton, and feature toggle system through TenantFeature flag list. Protocol-based ThemeManager with DefaultTheme/AthleteTheme implementations and remote theme fetching for real-time branding updates.
  • Protocol-Oriented Networking — Built networking layer using HTTPClient protocol with generic async/await methods (getRequest/postRequest), Endpoint protocol for URL construction, and request/response decoding with comprehensive error handling (invalidURL, unauthorized, decode, networkNotAvailable). Services follow a BiometricFetchable protocol pattern with dependency-injected NetworkMonitor for connectivity-aware API calls. All services wrapped in Handler layer for business logic separation.
  • Video Upload Optimization — Migrated video uploads from Base64 string encoding to multipart form-data using URLSession.upload with {tenant, testId, height, exerciseName, videoFileURL} fields, eliminating in-memory Base64 encoding of large video files and reducing payload sizes by 60%+ for post-assessment reports. Implemented MovementRecoveryManager with retry queue for failed uploads and temporary video file cleanup.
